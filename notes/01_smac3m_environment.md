# 单元 1：走进 SMAC3m 的一个回合

本单元只回答一件事：MAPT 最终读到的多智能体经历是什么。先看见环境给了什么，再谈它如何从偏好中学习。

## 直觉

把 `3m` 想成双方各有 3 名 Marine 的微型即时战略战斗。学习方不是一个“全知玩家”，而是 3 个并行决策的单位。每一步，每个存活单位根据自己的观测选一个动作；环境推进战斗，并给团队一个共享回报。

一个回合可以写成：

```text
观测 o_t 和合法动作掩码 m_t
          ↓ 每名单位的策略 π(a_t^i | o_t^i, m_t^i)
三个动作 a_t = (a_t^1, a_t^2, a_t^3)
          ↓ StarCraft II 推进
下一观测 o_{t+1}、环境回报 r_t、终止标记 done_t
          ↺ 重复直到战斗结束
```

这里的环境回报来自 SMAC 任务本身，例如造成敌方损伤、击杀和获胜时的奖励；代码默认还会按最大回报做缩放。它不是人类偏好标签，也不是 MAPT 学出来的奖励。后面的偏好学习会把两段经历交给偏好标签，再学习一个可供策略训练使用的奖励模型。

## 记号和形状

| 符号 | 含义 | 3m 中的一次检查 |
| --- | --- | --- |
| `N` | 我方智能体数 | 3 |
| `o_t^i` | 第 `i` 个单位在时刻 `t` 的局部观测向量 | 每个单位一个向量，长度由环境配置计算 |
| `m_t^i` | 第 `i` 个单位的可用动作掩码 | 长度 9；`1` 表示当前可选，`0` 表示不可选 |
| `a_t^i` | 第 `i` 个单位选的离散动作 | `0..8`，但存活单位通常不能选 0 |
| `r_t` | 该环境步的团队任务回报 | 环境会复制给 3 个单位的记录槽 |
| `done_t` | 战斗是否结束 | 环境内部按单位返回布尔值；整场结束时都为真 |

堆叠一段长度 `T` 的实际经历时，局部观测是 `[T, N, O]`，动作是 `[T, N]`，回报是 `[T]`（或记录时复制成 `[T, N, 1]`）。`O` 不应凭印象硬编码，运行入口会从环境返回值读取。

3m 的动作编号在作者环境实现里是：`0` 死亡单位的 no-op，`1` 停止，`2..5` 向四个方向移动，`6..8` 分别攻击三个敌方目标。可用动作掩码会屏蔽当前不能攻击的敌人；因此策略必须先对非法动作做 mask，再采样或取最大值。

## 论文连接

论文第 2 页把多智能体状态写作 `o_t = (o_t^1, ..., o_t^N)`，联合动作写作 `a_t = (a_t^1, ..., a_t^N)`。一个偏好样本不是单步，而是两段长度为 `T` 的多智能体轨迹及标签：

```text
(σ⁰, σ¹, y),    σ = {(o_1, a_1), ..., (o_T, a_T)}
```

论文实验第 6 页说明偏好由脚本教师从回放轨迹生成：教师比较任务累计回报，给出更好的片段标签。它们是合成的教师偏好，并非论文实验中的真实人类标注。第一单元的随机短跑只用于认识环境，不会被称作作者的偏好数据或专家演示。
