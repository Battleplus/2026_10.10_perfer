# 单元 3：从两段轨迹到一个概率

## Bradley-Terry 比较

论文 Eq. (1) 是经典二选一偏好概率：先把每段轨迹的逐步奖励加起来，再对两段总分做 softmax。

```text
R(σ) = Σ_t r(o_t, a_t)
p(σ⁰ ≻ σ¹) = exp(R(σ⁰)) / (exp(R(σ⁰)) + exp(R(σ¹)))
```

这是二选一 softmax。奖励差越大，模型越确信其中一段更好；给两个片段加同一个常数不会改变概率。

论文 Eq. (2) 用交叉熵让预测偏好和标签一致。若一条样本的软目标为 `y=[y_0,y_1]`，对应的损失为 `-y_0 log p_0 - y_1 log p_1`。论文 Eq. (3) 再将简单累计分替换为时间权重和智能体依赖奖励的聚合：

```text
R_m = Σ_t w_t^m · AGG({r_hat_n,t^m : n=1..N})
p(σ⁰ ≻ σ¹) = exp(R_0) / (exp(R_0) + exp(R_1))
```

这里 `m` 表示片段编号，`n` 表示智能体。之后用偏好标签和预测概率之间的交叉熵训练模型。

## 手算一次

设片段 A 的总分 `R_0=2`，片段 B 的总分 `R_1=1`：

```text
p(A 优于 B) = exp(2)/(exp(2)+exp(1)) = sigmoid(1) ≈ 0.731
```

若标签偏好 A，目标为 `[1, 0]`，单样本交叉熵约为 `-ln(0.731)=0.313`。如果两段同分，概率是 `[0.5,0.5]`；标签也可记为平局目标 `[0.5,0.5]`。

## 代码中的标签和损失

`mat/algorithms/reward_model/utils/dataloader.py` 把原始标签 `1` 映射为 `[1,0]`，`-1` 映射为 `[0,1]`，`0` 映射为 `[0.5,0.5]`。`MultiPrefTransformer._train_pref_step` 分别给两段轨迹打分，拼成两个 logits，再调用 `cross_ent_loss`。

PyTorch `F.cross_entropy(logits, target)` 接受类别概率形式的浮点目标，所以 `[0.5,0.5]` 表示平局监督。它和“标签类别 id 为 0 或 1”的整数目标是两种输入格式。

## 数据形状

对一个 batch：观测 `[B,T,N,O]`、动作 `[B,T,N,1]`（离散动作 id）、时间步 `[B,T]`、成对标签 `[B,2]`。模型输出每一步、每个智能体的分数 `[B,T,N,1]`；默认全局偏好模式先沿 `N` 求和，再沿 `T` 求和，得到每段 `[B,1]`，最后拼成 `[B,2]` logits。
